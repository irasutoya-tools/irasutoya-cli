# irasutoya-cli

A command-line tool for Ruby developers and terminal users who want to search, preview, and
download free illustrations from [いらすとや](https://www.irasutoya.com/) without leaving the
terminal.

- [Getting started](getting-started.md) covers installation and a first walkthrough.
- [CLI reference](usage.md) covers every command's arguments, options, and output.
- [Architecture](architecture.md) is where contributors should start reading the code.
- [FAQ and troubleshooting](troubleshooting.md) covers common questions and known failure modes.

See the [README](https://github.com/irasutoya-tools/irasutoya-cli#readme) for the project
overview, and the [source on GitHub](https://github.com/irasutoya-tools/irasutoya-cli).
