# Changelog

## [1.0.1](https://github.com/irasutoya-tools/irasutoya-cli/compare/v1.0.0...v1.0.1) (2026-02-03)

- Constrained the gem's runtime dependencies to `irasutoya ~> 2.0` and
  `terminal_image ~> 1.0`.

## [1.0.0](https://github.com/irasutoya-tools/irasutoya-cli/compare/v0.2.0...v1.0.0) (2025-06-21)

- Raised the minimum Ruby version from 2.5 to 3.1.

## [0.2.0](https://github.com/irasutoya-tools/irasutoya-cli/compare/v0.1.0...v0.2.0) (2020-11-06)

- Added the `search QUERY` command, which fetches up to three matching
  illustration pages.
- Listed and previewed every image on a result page for both `search` and
  `random`.

## [0.1.0](https://github.com/irasutoya-tools/irasutoya-cli/tree/v0.1.0) (2019-09-16)

- Initial RubyGems release with the `random` command, which prints a randomly
  selected illustration's metadata and attempts to show an inline preview.
